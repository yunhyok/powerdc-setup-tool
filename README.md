# SPD Manipulator for PowerDC

`powerdc-setup-tool` is a Windows GUI (PySide6) for taking a PowerSI `.spd` file, letting the
user pick and classify nets, pair power/ground, and set voltages/currents, then writing a new
PowerDC-ready `.spd` with generated `.VRM`/`.Sink` blocks.

Full usage, packaging, and distribution docs are completed in the packaging chunk.
